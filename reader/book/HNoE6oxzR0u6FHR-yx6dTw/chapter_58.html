প্রতি-প্রসব (p. 541) [ prati-prasaba ] বি. পূর্বনিষিদ্ধ বিধানের পূনঃপ্রবর্তন, নতুন বিধানের দ্বারা নিষিদ্ধ বিধির পুনঃপ্রবর্তন। [সং. প্রতি + প্র + √ সূ + অ]। প্রতি-প্রসূত বিণ. 1 নতুন বিধির দ্বারা পূর্বনিষিদ্ধ বিধান পুনঃপ্রবর্তিত হয়েছে এমন; 2 পুনঃসম্ভাবিত।

 

প্রতি-প্রস্হান (p. 541) [ prati-prashāna ] বি. শত্রুর বা বিপক্ষের আশ্রয়; বিপক্ষের আশ্রয় গ্রহণ; বিপক্ষে চলে যাওয়া। [সং. প্রতি + প্রস্হান]।

 

প্রতি-প্রহার (p. 541) [ prati-prahāra ] বি. 1 প্রতিঘাত, পালটা আঘাত; 2 পালটা প্রহার। [সং. প্রতি + প্রহার]।

 

প্রতি-ফল (p. 541) [ prati-phala ] বি. 1 প্রতিশোধ; 2 শাস্তি (এর প্রতিফল তোমাকে পেতেই হবে)। [সং. প্রতি + ফল]।

 

প্রতি-ফলন (p. 541) [ prati-phalana ] বি. 1 প্রতিবিম্বপাত (সাহিত্য লেখকের মনের প্রতিফলন); 2 দর্পণ ইত্যাদিতে পতিত আলোকের প্রত্যাবর্তন, reflection. [সং. প্রতি + √ ফল্ + অন]।

 

প্রতি-ফলিত (p. 541) [ prati-phalita ] বিণ. 1 প্রতিবিম্বিত; 2 পতিত আলোক প্রত্যাবৃত্ত হয়েছে এমন বা ওই আলোকে উদ্ভাসিত, reflected. [সং. প্রতি + √ ফল্ + ত]।

 

প্রতি-বচন (p. 541) [ prati-bacana ] বি. 1 উত্তর বা প্রত্যুত্তর; 2 প্রতিকূল বাক্য; 3 সমানার্থক বাক্য; 4 প্রতিধ্বনি। [সং. প্রতি + বচন]।

 

প্রতি-বদ্ধ (p. 541) [ prati-baddha ] বিণ. বাধাপ্রাপ্ত; ব্যাহত (প্রতিবদ্ধ বায়ু, প্রতিবদ্ধ আলো)। [সং. প্রতি + বদ্ধ]।

 

প্রতি-বন্ধ (p. 541) [ prati-bandha ] বি. বাধা, ব্যাঘাত, বিঘ্ন, অন্তরায়। [সং. প্রতি + √ বন্ধ্ + অ]। ̃ ক বিণ. বাধাজনক; পরিপন্হী। ☐ বি. বাধা, অন্তরায় (পদে পদে প্রতিবন্ধক)। ̃ কতা বি. 1 বাধাদান (কাজে প্রতিবন্ধকতা করা); 2 বাধা (কাজে প্রতিবন্ধকতা সৃষ্টি করা)। প্রতি-বন্ধী (-ন্ধিন্) বিণ. বি. বাধাযুক্ত; বাধাজনক; দৈহিক শক্তির একান্ত অভাবের জন্য বা অঙ্গহানির জন্য যারা আশৈশব বাধাপ্রাপ্ত মূক বধির খঞ্জ ইত্যাদি।

 

প্রতি-বর্ণী-করণ (p. 541) [ prati-barṇī-karaṇa ] বি. এক ভাষার শব্দ অন্য ভাষার লিপি বা বর্ণে লেখা, লিপ্যন্তরীকরণ, transliteration. [সং. প্রতি + বর্ণ + চি + করণ]। বিণ. প্রতি-বর্ণী-কৃত।

 

প্রতি-বর্তন (p. 541) [ prati-bartana ] বি. 1 বিপরীত দিক বা মুখ উপস্হিতকরণ, obversion (বি.প.); 2 ফেরা, প্রত্যাবর্তন। [সং. প্রতি + √ বৃত্ + ণিচ্ + অন]।

 

প্রতি-বল (p. 541) [ prati-bala ] বি. শত্রুপক্ষের বা বিপক্ষের সৈন্য বা সৈন্যবল। ☐ বিণ. সমান শক্তিসম্পন্ন। [সং. প্রতি + বল]।

 

প্রতি-বস্তুপমা (p. 541) [ prati-bastupamā ] বি. উপমান বা উপমেয়ের সাধারণ ধর্মের পার্থক্য সত্ত্বেও সাদৃশ্য বোধগম্য হয় এণন অর্থালংকারবিশেষ। [সং. প্রতিবস্তু + উপমা]।

 

প্রতি-বাক্য (p. 541) [ prati-bākya ] বি. 1 উত্তর; 2 প্রত্যুত্তর; 3 প্রতিকূল বাক্য। [সং. প্রতি + বাক্য]।

 

প্রতি-বাত (p. 541) [ prati-bāta ] বিণ. ক্রি-বিণ. বায়ুর প্রতিকূল বা প্রতিকূলে, যেদিক থেকে বায়ু বইছে সেই দিক বা দিকে। ☐ বি. প্রতিকূল বায়ু, উলটো দিক থেকে আগত বায়ু। [সং. প্রতি + বাত2]।

 

প্রতি-বাদ (p. 541) [ prati-bāda ] বি. 1 কোনো উক্তি খণ্ডনের জন্য প্রত্যুক্তি; 2 আপত্তিজ্ঞাপন (অন্যায়ের প্রতিবাদ করা); 3 বিরুদ্ধ উক্তি। [সং. প্রতি + √ বদ্ + অ]। প্রতি-বাদী (-দিন্) বিণ. বি. 1 বিরুদ্ধবাদী; 2 প্রতিপক্ষ; 3 বিবাদী; 4 আসামি। স্ত্রী. প্রতিবাদিনী।

 

প্রতি-বাসর (p. 541) [ prati-bāsara ] বি. প্রতিদিন। [সং. প্রতি + বাসর (=দিবস)]।

 

পতি-বাসী (p. 541) [ pati-bāsī ] (-সিন্) বিণ. বি. প্রতিবেশী, পড়শি, নিকটে বা কাছাকাছি বাসকারী। [সং. প্রতি + √ বস্ + ইন্]। স্ত্রী. প্রতি-বাসিনী।

 

প্রতি-বিধান (p. 541) [ prati-bidhāna ] বি. 1 প্রতিকার; 2 নিরাময় বা দূরীকরণের উপায় (রোগের প্রতিবিধান); 3 প্রতিশোধ। [সং. প্রতি + বিধান]। বিণ. প্রতি-বিহিত।

 

প্রতি-বিধিত্সা (p. 541) [ prati-bidhitsā ] বি. প্রতিকার বা প্রতিবিধানের ইচ্ছা। [সং. প্রতি + বি + √ ধা + সন্ + অ + আ]।

 

প্রতি-বিপ্লব (p. 541) [ prati-biplaba ] বি. কোনো বিপ্লবের বিরুদ্ধবাদীদের দ্বারা পরিচালিত আর এক বিপ্লব, counter-revolution. [সং. প্রতি + বিপ্লব]। প্রতি-বিপ্লবী বিণ. প্রতিবিপ্লবমূলক; প্রতিবিপ্লবপন্হী। ☐ বি. প্রতিবিপ্লবপন্হী বা প্রতিবিপ্লবকারী ব্যক্তি।

 

প্রতি-বিম্ব (p. 541) [ prati-bimba ] বি. দর্পণ জল প্রভৃতিতে প্রতিফলিত মূর্তি, প্রতিচ্ছায়া ('জলে প্রিয় মুখের প্রতিবিম্ব': অ. মি.)। [সং. প্রতি + বিম্ব]। ̃ ন বি. প্রতিফলন, প্রতিবিম্বপাত। প্রতি-বিম্বিত বিণ. প্রতিফলিত; প্রতিবিম্ব ফেলেছে বা পড়েছে এমন (জাতীয় চরিত্র সাহিত্যে প্রতিবিম্বিত)।

 

প্রতি-বিহিত (p. 541) [ prati-bihita ] বিণ. প্রতিকার বা প্রতিবিধান করা হয়েছে এমন। [সং. প্রতি + বি + √ ধা + ত]।

 

প্রতি-বেদক (p. 541) [ prati-bēdaka ] বি. (প্রধানত সংবাদ প্রচারের জন্য) বিবরণদাতা, reporter. [সং. প্রতি + √ বিদ্ + ণিচ্ + অক]। প্রতি-বেদন বি. 1 অভাব-অভিযোগ জ্ঞাপন; 2 বিবরণ; 3 রিপোর্ট, report.

 

প্রতি-বেশ (p. 541) [ prati-bēśa ] বি. 1 কাছাকাছি অবস্হিত ঘরবাড়ি; 2 প্রতিবাসীদের গৃহ; 3 পরিপার্শ্ব বা পরিপার্শ্বের অবস্হা, পরিবেশ। [সং. প্রতি + √ বিশ্ + অ]।

 

প্রতি-বেশী (p. 541) [ prati-bēśī ] (-শিন্) বিণ. বি. নিকটবর্তী স্হানে বাসকারী, কাছাকাছি বাসকারী, পড়শি। [সং. প্রতি + √ বিশ্ + ইন্]। স্ত্রী. প্রতি-বেশিনী।

 

প্রতিবোধ, প্রতিবোধন (p. 541) [ pratibōdha, pratibōdhana ] বি. 1 বিকাশ; 2 জাগরণ; 3 বোধের উন্মেষ; 4 বুঝিয়ে বা জাগিয়ে দেওয়া। [সং. প্রতি + বোধ, বোধন]। বিণ. প্রতি-বোধিত।

 

প্রতিভা (p. 541) [ pratibhā ] বি. 1 স্বভাবজাত ও অসামান্য বুদ্ধি (কবিপ্রতিভা, বৈজ্ঞানিক প্রতিভা); 2 প্রত্যুত্পন্নমতিত্ব; 3 উদ্ভাবনী বুদ্ধি; 4 সৃজনশীল প্রজ্ঞা; 5 প্রভা, দীপ্তি। [সং. প্রতি + √ ভা + অ]। ̃ ধর, ̃ শালী বিণ. প্রতিভা আছে এমন, প্রতিভাযুক্ত, প্রতিভাসম্পন্ন। ̃ বান বিণ. প্রতিভাসম্পন্ন।

 

প্রতি-ভাত (p. 541) [ prati-bhāta ] বিণ. 1 উজ্জলরূপে প্রকাশিত; 2 স্পষ্টভাবে ব্যক্ত (তিনি ভক্তহৃদয়ে অবতার রূপে প্রতিভাত); 3 জ্ঞাত; 4 আলোকিত; 5 প্রতিফলিত। [সং. প্রতি + √ ভা + ত]।

 

প্রতি-ভাস (p. 541) [ prati-bhāsa ] বি. 1 মনের মধ্যে আকস্মিক প্রকাশ; 2 প্রকাশ; 3 উজ্জ্বলতা, দীপ্তি। [সং. প্রতি + √ ভাস্ (=দীপ্তি) + অ]। প্রতি-ভাসিত বিণ. ব্যক্ত, প্রকাশিত; শোভিত; প্রভাযুক্ত; দীপ্ত।

 

প্রতিভূ (p. 541) [ pratibhū ] বি. 1 প্রতিনিধি ('বৌদ্ধ সংস্কৃতি প্রাচ্য সভ্যতার প্রতিভূ': রবীন্দ্র); 2 জামিন। [সং. প্রতি + √ ভূ + ক্বিপ্]।

 

-প্রতিম (p. 541) [ -pratima ] বিণ. (অন্য শব্দের শেষে যুক্ত হয়ে) তুল্য, সদৃশ (অগ্রজপ্রতিম, প্রাণপ্রতিম)। [সং. প্রতি + √ মা + অ]।

 

প্রতিমা (p. 541) [ pratimā ] বি. 1 প্রতিমূর্তি, প্রতিকৃতি; 2 ঈশ্বরের কোনো রূপের সাদৃশ্যকল্পনায় গঠিত বা নির্মিত দেবমূর্তি; 3 বিগ্রহ, মূর্তরূপ (সৌন্দর্যের প্রতিমা)। [সং. প্রতি + √ মা + অ + আ]।

 

প্রতি-মান (p. 541) [ prati-māna ] বি. 1 নজির, নিদর্শন, প্রমাণ; 2 মানদণ্ড, বিচারের মাপকাঠি; 3 মান, standard. [সং. প্রতি + মান2]।

 

প্রতি-মুক্ত (p. 541) [ prati-mukta ] বিণ. 1 মুক্ত; 2 বন্ধনযুক্ত; 3 পরিত্যক্ত। [সং. প্রতি + মুক্ত]।

 

প্রতি-মুখ (p. 541) [ prati-mukha ] বি. 1 অভিমুখ; 2 সম্মুখ। [সং. প্রতি + মুখ]।

 

প্রতি-মূহুর্ত (p. 541) [ prati-mūhurta ] ক্রি-বিণ. প্রতিক্ষণ, সর্বদা। [সং. প্রতি + মুহুর্ত]।

 

প্রতি-মূর্তি (p. 541) [ prati-mūrti ] বি. 1 প্রতিকৃতি; 2 অনুরূপ মূর্তি বা চেহারা; 3 প্রতিমা। [সং. প্রতি + মূর্তি]।

 

প্রতি-যোগ (p. 541) [ prati-yōga ] বি. 1 শত্রুতা; 2 বিরোধ; 3 প্রতিদ্বন্দ্বিতা। [সং. প্রতি + যোগ]। প্রতি-যোগিতা বি. 1 প্রতিদ্বন্দ্বিতা; 2 বিরোধিতা, বিপক্ষতা; 3 সমকক্ষতা। প্রতি-যোগী (-গিন্) বিণ. বি. প্রতিদ্বন্দী; পরস্পর শক্তিপরীক্ষাকারী; বিপক্ষ, পতিপক্ষ; সমকক্ষ। স্ত্রী. প্রতি-যোগিনী।

 

প্রতি-রক্ষা, প্রতি-রক্ষণ (p. 543) [ prati-rakṣā, prati-rakṣaṇa ] বি. সম্ভাব্য বহিরাক্রমণ থেকে দেশ বা রাষ্ট্রের রক্ষাব্যবস্হা, আরক্ষা, defence. [সং. প্রতি + রক্ষা, রক্ষণ]। প্রতি-রক্ষা-বাহিনী বি. প্রতিরক্ষার কাজে নিযুক্ত সৈন্যবাহিনী।

 

প্রতিরব (p. 543) [ pratiraba ] বি. প্রতিধ্বনি। [সং. প্রতি + রব]।

 

প্রতিরুদ্ধ (p. 543) [ pratiruddha ] দ্র প্রতিরোধ।

 

প্রতি-রূপ (p. 543) [ prati-rūpa ] বি. 1 প্রতিমূর্তি (নালন্দা ছিল আধুনিক বিশ্ববিদ্যালয়েরই প্রতিরূপ); 2 সাদৃশ্য; প্রতিবিম্ব। ☐ বিণ. সদৃশ, তুল্য। [সং. প্রতি + রূপ]। প্রতি-রূপক বি. 1 চিত্র; 2 প্রতিবিম্ব; 3 প্রতিমূর্তি।

 

প্রতি-রোধ (p. 543) [ prati-rōdha ] বি. 1 নিবারণ (রোগ প্রতিরোধ); 2 বাধাদান (অন্যায়ের প্রতিরোধ); 3 অবরোধ; 4 আটক; 5 প্রতিবন্ধ, ব্যাঘাত। [সং. প্রতি + রোধ]. প্রতি-রুদ্ধ, প্রতি-রোধিত বিণ. প্রতিরোধ করা হয়েছে এমন; বাধাপ্রাপ্ত; নিবারিত। ̃ ক, প্রতিরোধী (-ধিন্) বিণ. প্রতিরোধকারী। প্রতিরোধ্য বিণ. প্রতিরোধ করা সম্ভব বা উচিত এমন।

 

প্রতিলিপি (p. 543) [ pratilipi ] বি. রচনা ছবি প্রভৃতির যথাযথ নকল, copy. [সং. প্রতি + লিপি]।

 

প্রতি-লোম (p. 543) [ prati-lōma ] বিণ. 1 বিপরীত, উলটো ('প্রতিলোম অভিযানে লোকযাত্রী হবে অগ্রসর': সু. দ.); 2 প্রতিকূল (প্রতিলোম আচরণ)। [সং. প্রতি + লোমন্ + অ]। প্রতিলোম বিবাহ নিম্নবংশীয় পুরুষের সঙ্গে উচ্চবংশীয় কন্যার বিবাহ।

 

প্রতি-শব্দ (p. 543) [ prati-śabda ] বি. 1 সমার্থক শব্দ, একই অর্থবোধক শব্দ; 2 প্রতিধ্বনি। [সং. প্রতি + শব্দ]।

 

প্রতি-শয়, প্রতি-শয়ন (p. 543) [ prati-śaẏa, prati-śaẏana ] বি. দেবমন্দিরে প্রত্যাদেশ কামনায় ধরনা বা হত্যা দেওয়া। [সং. প্রতি + √ শী + অ, অন]।

 

প্রতি-শোধ (p. 543) [ prati-śōdha ] বি. 1 অন্যায়ের প্রত্যুত্তরে অন্যায়কারীর ক্ষতিসাধন; 2 প্রতিহিংসা। [সং. প্রতি + শোধ]।

 

প্রতি-শ্রয় (p. 543) [ prati-śraẏa ] বি. 1 সভা, সভাগৃহ; 2 যজ্ঞশালা; 3 পাত্র, আধার। [সং. প্রতি + √ শ্রি + অ]।

 

প্রতি-শ্রুতি (p. 543) [ prati-śruti ] বি. কথা দেওয়া; অঙ্গীকার, প্রতিজ্ঞা। [সং. প্রতি + √ শ্রু + তি]। প্রতি-শ্রুত বিণ. অঙ্গীকৃত, প্রতিজ্ঞাবদ্ধ।

 

প্রতি-ষেধ (p. 543) [ prati-ṣēdha ] বি. 1 নিষেধ; 2 নিবারণ (রোগ প্রতিষেধ); 3 ত্যাগ, বর্জন। [সং. প্রতি + √ সিধ্ + অ]। প্রতি-ষিদ্ধ বিণ. প্রতিষেধ করা হয়েছে এমন। ̃ ক বিণ. প্রতিরোধ বা নিবারণ করে এমন, নিবারক (প্রতিষেধক টিকা)। ☐ বি. প্রতিষেধক পদার্থ। ̃ ন বি. প্রতিষেধকরণ।

 

প্রতি-ষ্টম্ভ (p. 543) [ prati-ṣṭambha ] বি. 1 বাধা, প্রতিবন্ধ, আটকে দেওয়া (বাহু প্রতিষ্টম্ভ); 2 প্রতিরোধ। [সং. প্রতি + √ স্তম্ভ্ + অ]।

 

প্রতিষ্ঠা (p. 543) [ pratiṣṭhā ] বি. 1 সংস্হাপন (বিদ্যালয় প্রতিষ্ঠা); 2 (ব্রতাদি) উদ্ যাপন ; 3 উত্সর্গ (বৃক্ষ প্রতিষ্ঠা); 4 অবস্হান, যাতে স্হিতি লাভ হয় (কুলপ্রতিষ্ঠা); 5 প্রতিপত্তি, খ্যাতি, গৌরব (সমাজে প্রতিষ্ঠা লাভ)। [সং. প্রতি + √ স্হা + অ + আ]। ̃ তা (-তৃ) বিণ. বি. প্রতিষ্ঠাকারী। স্ত্রী. ̃ ত্রী। ̃ ন বি. 1 সংস্হাপন; 2 বিশেষ উদ্দেশ্যে গঠিত সমিতি বা সংস্হা, institution (শিক্ষাপ্রতিষ্ঠান, ধর্মীয় প্রতিষ্ঠান); 3 অবস্হান; 4 প্রাচীন ভারতের নগরবিশেষ। ̃ বান (-বত্) বিণ. বিখ্যাত; বিশেষ গৌরবসম্পন্ন (চিকিত্সাশাস্ত্রে দিশবিদেশে প্রতিষ্ঠাবান)। প্রতিষ্ঠিত বিণ. 1 প্রতিষ্ঠা করা হয়েছে এমন (মন্দির প্রতিষ্ঠিত হয়েছে); 2 প্রতিষ্ঠা লাভ করেছে এমন (পসার প্রতিষ্ঠিত); 3 বদ্ধমূল (প্রতিষ্ঠিত বিশ্বাস)।

 

প্রতিষ্ঠা-পন (p. 543) [ pratiṣṭhā-pana ] বি. 1 সংস্হাপন, প্রতিষ্ঠা; 2 উত্সর্গ; 3 অর্পণ। [সং. প্রতি + √ স্হা + ণিচ্ + অন]। প্রতিষ্ঠা-পয়িতা (-তৃ) বিণ. বি. প্রতিষ্ঠাকারী। স্ত্রী. প্রতিষ্ঠা-পয়িত্রী। প্রতিষ্ঠা-পিত বিণ. প্রতিষ্ঠা করা হয়েছে এমন।

 

প্রতিষ্ঠিত (p. 543) [ pratiṣṭhita ] দ্র প্রতিষ্ঠা।

 

প্রতি-সংহার (p. 543) [ prati-saṃhāra ] বি. 1 (অস্ত্রাদি) সংবরণ; 2 নিবর্তন; 3 ফিরিয়ে নেওয়া। [সং. প্রতি + সম্ + √ হৃ + অ]। প্রতি-সংহৃত বিণ. ফিরিয়ে নেওয়া হয়েছে এমন।

 

প্রতি-সন্ধান (p. 543) [ prati-sandhāna ] বি. 1 অনুসন্ধান, অন্বেষণ; 2 অনুচিন্তন, অবধান। [সং. প্রতি + সন্ধান]।

 

প্রতিসব্য (p. 543) [ pratisabya ] বিণ. 1 প্রতিকূল; 2 বিপরীত। [সং. প্রতি + সব্য (বাম)]।

 

প্রতি-সর (p. 543) [ prati-sara ] বি. কঙ্কণ বা হাতের বালাবিশেষ। [সং. প্রতি + √ সৃ + অ]।

 

প্রতি-সরণ (p. 543) [ prati-saraṇa ] বি. (বিজ্ঞা.) এক স্বচ্ছ পদার্থ থেকে ভিন্ন স্বচ্ছ পদার্থে প্রবেশ করলে আলোকরশ্মির স্বাভাবিক গতিপথের যে পরিবর্তন হয়, refraction (বি.প.)। [সং. প্রতি + √ সৃ + অন]। প্রতি-সৃত বিণ. প্রতিসরণযুক্ত; পরাবর্তিত।

 

প্রতি-সর্গ (p. 543) [ prati-sarga ] বি. 1 ব্রহ্মার সৃষ্টিকার্যের পর তাঁর মানসপুত্রদের দ্বারা সৃষ্টি; 2 প্রলয়, মহাপ্রলয়। [সং. প্রতি + সর্গ (=স়ৃষ্টি)]।

 

প্রতি-সারণ (p. 543) [ prati-sāraṇa ] বি. দূরীকরণ, অপসারণ। [সং. প্রতি + √ সৃ + ণিচ্ + অন]। প্রতি-সারিত বিণ. 1 দূরীকৃত, অপসারিত; 2 সংশোধিত; 3 পরিচালিত।

 

প্রতি-সারী (p. 543) [ prati-sārī ] (-রিন্) বিণ. বিপরীতগামী বা প্রতিকূলগামী। [সং. প্রতি + √ সৃ + ইন্]।

 

প্রতিসৃত (p. 543) [ pratisṛta ] দ্র প্রতিসরণ।

 

প্রতি-সৃষ্ট (p. 543) [ prati-sṛṣṭa ] বিণ. 1 নিক্ষিপ্ত; 2 বিক্ষিপ্ত; 3 প্রত্যাখ্যাত। [সং. প্রতি + √ সৃজ্ (=বিসর্জন) + ত]।

 

প্রতি-স্পর্ধা (p. 543) [ prati-spardhā ] বি. প্রতিদ্বন্দ্বিতা, প্রতিযোগিতা। [সং. প্রতি + স্পর্ধা]। প্রতি-স্পর্ধী (-র্ধিন্) বিণ. 1 প্রতিদ্বন্দ্বী, প্রতিযোগী; 2 সমকক্ষ।

 

প্রতি-স্বর (p. 543) [ prati-sbara ] বি. প্রতিধ্বনি। [সং. প্রতি + স্বর]।

 

প্রতি-হত (p. 543) [ prati-hata ] বিণ. 1 বাধাপ্রাপ্ত (অপচেষ্ঠা প্রতিহত); 2 আঘাতপ্রাপ্ত, আহত; 3 নিবারিত; 4 ব্যাহত। [সং. প্রতি + √ হন্ + ত]।

 

প্রতি-হনন (p. 543) [ prati-hanana ] বি. 1 হত্যাকারীকে বধ; 2 হত্যার জবাবে হত্যা, পালটা হত্যা। [সং. প্রতি + হনন]।

 

প্রতি-হন্তা (p. 543) [ prati-hantā ] (-ন্তৃ) বিণ. বি. হত্যাকারী বা আঘাতকারীকে যে বধ করে। [সং. প্রতি + হন্তৃ]।

 

প্রতি-হর্তা (p. 543) [ prati-hartā ] (-র্তৃ) বিণ. বি. 1 প্রত্যাঘাতকারী; 2 নিবারণকারী। [সং. প্রতি + √ হৃ + তৃ]।

 

প্রতি-হার (p. 544) [ prati-hāra ] বি. 1 দৌরারিক, দ্বাররক্ষী; 2 পরিহার, বর্জন; 3 (বিরল) সদর দরজা। [সং. প্রতি + √ হৃ + অ]। প্রতি-হারী (-রিন্) বি. দৌবারিক, দ্বাররক্ষী। স্ত্রী. প্রতি-হারিণী।

 

প্রতি-হারক (p. 544) [ prati-hāraka ] বিণ. 1 ঐন্দ্রজালিক, জাদুকর; 2 ছলনাকারী, প্রতারক। [সং. প্রতি + √ হৃ + অক]। প্রতি-হারণ বি. 1 প্রবেশদ্বার; 2 দ্বারে প্রবেশের অনুমতি।

 

প্রতিহারী (p. 544) [ pratihārī ] দ্র প্রতিহার।

 

প্রতি-হার্য (p. 544) [ prati-hārya ] বিণ. পরিহারযোগ্য, বর্জনীয়। [সং. প্রতি + √ হৃ + য]।

 

প্রতি-হিংসা (p. 544) [ prati-hiṃsā ] বি. 1 হিংসার বদলে হিংসা; 2 প্রতিশোধ; 3 বৈরনির্যাতন, শত্রুতাকারীর প্রতি শত্রুতাচরণ। [সং. প্রতি + হিংসা]।

 

প্রতীক (p. 544) [ pratīka ] বি. 1 অবয়ব, অঙ্গ; 2 প্রতিমা; 3 চিহ্ন; 4 ঈশ্বর ইত্যাদি অকল্পনীয় বা বিরাট ব্যাপারের কল্পনার সহায়ক বস্তু বা রূপ, (প্রতীক-উপাসনা)। ☐ বিণ. প্রতিকূল। [সং. প্রতি + √ ই + ঈক]। ̃ তা, ̃ বাদ, প্রতীকী-বাদ বি. সাহিত্যে, বিশেষত কাব্যে, সংকেত দ্বারা ভাবপ্রকাশের পদ্ধতি বা রীতি, symbolism. প্রতীকী বিণ. 1 সংকেতময়, ইঙ্গিতময়; 2 সাংকেতিক, symbolic ('ছাই হয়ে গেছে প্রতীকী স্বর্ণলঙ্কা': সু. দ.)।

 

প্রতীক্ষমাণ (p. 544) [ pratīkṣamāṇa ] দ্র প্রতীক্ষা।

প্রত্যা-বর্তন (p. 544) [ pratyā-bartana ] বি. ফিরে আসা, প্রত্যাগমন। [সং. প্রতি + আবর্তন]। প্রত্যা-বৃত্ত বিণ. ফিরে এসেছে এমন। স্ত্রী. প্রত্যাবৃত্তা। প্রত্যা-বৃত্তি বি. 1 প্রত্যাবর্তন; 2 পশ্চাদ্গামিতা, পশ্চাদপসরণ, regression. (বি. প.)।

 

প্রত্যায়ন (p. 544) [ pratyāẏana ] বি. 1 বিশ্বাস উত্পাদন, প্রত্যয় উত্পাদন; 2 সূচনা, উদ্বোধন। [সং. প্রতি + √ ই + ণিচ্ + অন]।

 

প্রত্যারম্ভ (p. 544) [ pratyārambha ] বি. নতুন করে আরম্ভ, পুনরারম্ভ। [সং. প্রতি + আরম্ভ]।

 

প্রত্যা-লীঢ় (p. 544) [ pratyā-līḍh় ] বি. তির নিক্ষেপের সময় বাঁ পা ছড়িয়ে এবং ডান পা ভাঁজ করে বসা বা বসার ভঙ্গি। ☐ বিণ. ভক্ষিত, ভুক্ত। [সং. প্রতি + আ + √ লিহ্ + ত]।

 

প্রত্যাশা (p. 544) [ pratyāśā ] বি. 1 আশা, কামনা (তোমার এই আচরণ প্রত্যাশা করিনি); 2 প্রাপ্তির সম্ভাবনা বা আশা (লাভের প্রত্যাশা, ভারতের কাছে বিশ্বের প্রত্যাশা); 3 প্রতীক্ষা। [সং. প্রতি + আশা]। প্রত্যাশিত বিণ. 1 প্রত্যাশা করা হয়েছে এমন (প্রত্যাশিত সংবাদ); 2 সম্ভাবিত। প্রত্যাশী (-শিন্) বিণ. প্রত্যাশাকারী (সম্মানের প্রত্যাশী)।

 

প্রত্যাসন্ন (p. 544) [ pratyāsanna ] বিণ. অতি আসন্ন, একেবারে নিকটবর্তী। [সং. প্রতি + আসন্ন]।

 

প্রত্যাহত (p. 544) [ pratyāhata ] বিণ. 1 বাধাপ্রাপ্ত, ব্যাহত; 2 নিবারিত; 3 সংকুচিত। [সং. প্রতি + আহত]।

 

প্রত্যা-হরণ, প্রত্যা-হার (p. 544) [ pratyā-haraṇa, pratyā-hāra ] বি. 1 ফিরিয়ে নেওয়া (মন্তব্য প্রত্যাহার, ধর্মঘট প্রত্যাহার); 2 (দর্শ.) কাম্য বস্তু থেকে ইন্দ্রিয়বৃত্তির নিরোধ, ইন্দ্রিয়গুলিকে সবলে বিষয় থেকে আকর্ষণ। [সং. প্রতি + আ + √ হৃ + অন, অ]। প্রত্যা-হৃত বিণ. প্রত্যাহার করা হয়েছে এমন।

 

প্রত্যুক্তি (p. 544) [ pratyukti ] বি. উত্তর, জবাব; কথার জবাবে কথা, পালটা জবাব। [সং. প্রতি + উক্তি]।

 

প্রত্যুত (p. 544) [ pratyuta ] অব্য. পরন্তু, পক্ষান্তরে, বরং। [সং. প্রতি + উত]।

 

প্রত্যুত্তর (p. 544) [ pratyuttara ] বি. উত্তরের উত্তর; উত্তর, জবাব (কোনো প্রত্যুত্তর করল না)। [সং. প্রতি + উত্তর]।

 

প্রত্যুত্থান (p. 544) [ pratyutthāna ] বি. আগন্তুকের সম্মানার্থে উঠে দাঁড়ানো। [সং. প্রতি + উত্থান]। প্রত্যুত্থিত বিণ. প্রত্যুত্থান করেছে এমন।

 

প্রত্যুত্-পন্ন (p. 546) [ pratyut-panna ] বিণ. তত্ক্ষণাত্ উত্পন্ন বা জাত, সঙ্গে সঙ্গে উত্পন্ন, উপস্হিত। [সং. প্রতি + উত্পন্ন]। ̃ মতি বি. উপস্হিতবুদ্ধি, প্রয়োজনের সঙ্গে সঙ্গে বুদ্ধির স্ফুরণ। ☐ বিণ. উপস্হিতবুদ্ধিযুক্ত। ̃ মতিত্ব বি. উপস্হিতবুদ্ধি প্রয়োগের ক্ষমতা।

 

প্রত্যুদ্-গমন, প্রত্যুদ্-গম (p. 546) [ pratyud-gamana, pratyud-gama ] বি. আগন্তুককে অভ্যর্থনা করে আনার জন্য কিছুদূর এগিয়ে যাওয়া; কিছুদূর অগ্রসর হয়ে অভ্যর্থনা। [সং. প্রতি + উদ্ + √ গম্ + অন, অ]। প্রত্যুদ্গত বিণ. এগিয়ে গিয়ে অভ্যর্থনা করা হয়েছে এমন।

 

প্রত্যুদা-হরণ (p. 546) [ pratyudā-haraṇa ] বি. প্রদত্ত দৃষ্টান্তের দৃষ্টান্ত। [সং. প্রতি + উদাহরণ]।

 

প্রত্যুপ-কার (p. 546) [ pratyupa-kāra ] বি. উপকারের বিনিময়ে উপকার, উপকারীর উপকার। [সং. প্রতি + উপকার]। প্রত্যুপ-কর্তা (-র্তৃ), প্রত্যুপ-কারী (-রিন্) বিণ. উপকারীর উপকারকারী। প্রত্যুপ-কৃত বিণ. প্রত্যুপকারপ্রাপ্ত।

 

প্রত্যু-পদেশ (p. 546) [ pratyu-padēśa ] বি. উপদেশের প্রতিদানে বা জবাবে উপদেশ দান। [সং. প্রতি + উপদেশ]। প্রত্যুপদেষ্টা (-ষ্টৃ) বিণ. প্রত্যুপদেশ দানকারী।

 

প্রত্যুপ্ত (p. 546) [ pratyupta ] বিণ. 1 উপ্ত, রোপিত; 2 গ্রথিত। [সং. প্রতি + উপ্ত]।

 

প্রত্যুষ, প্রত্যূষ (p. 546) [ pratyuṣa, pratyūṣa ] বি. সূর্যোদয়ের সময়, প্রভাত, উষা, ভোর। [সং. প্রতি + √ উষ্ + অ, √ ঊষ্ + অ]।

 

প্রত্যূহ (p. 546) [ pratyūha ] বি. 1 বিরুদ্ধ তর্ক; 2 বিঘ্ন, বাধা, অন্তরায়। [সং. প্রতি + √ ঊহৃ + অ]।

 

প্রত্যেক (p. 546) [ pratyēka ] বিণ. প্রতিটি বা প্রতিজন, আলাদা আলাদা করে সকলে (প্রত্যেক দিন, প্রত্যেক মানুষ)। ☐ সর্ব. এক এক করে সকলে (প্রত্যেকই গিয়েছিল)। [সং. প্রতি + এক]।

 

প্রথম (p. 546) [ prathama ] বিণ. 1 আদি, আদিম (প্রথম যুগ, প্রথম প্রাণের আবির্ভাব); 2 আরম্ভকালীন (প্রথমাবস্হা); 3 শ্রেষ্ঠ, প্রধান (প্রথম পুরস্কার); 4 জ্যেষ্ঠ (প্রথম সন্তান); 5 নতুন, নবীন, অভিনব (প্রথম যৌবন); 6 পয়লা, এক নম্বর (মাসের প্রথম দিন); 7 সর্বাগ্রবর্তী (প্রথম সারি); 8 সর্বোত্কৃষ্ট, সর্বোচ্চ (পরীক্ষায় প্রথম হওয়া)। [সং. √ প্রথ্ + অম]। স্ত্রী. প্রথমা। ̃ ত (-তস্) অব্য. ক্রি-বিণ. প্রথমে, আগে; প্রধানত। প্রথম-প্রথম ক্রি-বিণ. গোড়ার দিকে। প্রথমোক্ত বিণ. প্রথমে বলা হয়েছে বা উল্লেখ করা হয়েছে এমন (প্রথমোক্ত পুস্তকটি)।

 

প্রথা (p. 546) [ prathā ] বি. 1 রীতি (প্রথাগত সৌজন্য); 2 প্রচলিত আচার, দেশাচার (সামাজিক প্রথা); 3 নিয়ম, পদ্ধতি (শিক্ষাদানের প্রথা)। [সং. √ প্রথ্ + অ + আ]। ̃ গত বিণ. 1 আইনাগনুগ, নিয়মনির্দিষ্ট; 2 অনেকদিন ধরে চলে আসছে এমন, প্রচলিত (প্রথাগত শিক্ষা)। ̃ নুগ বিণ. প্রথা অনুযায়ী। ̃ বিরুদ্ধ বিণ. প্রথার সঙ্গে মেলে না এমন, প্রথার সঙ্গে সংগতিহীন। ̃ মতো ক্রি-বিণ. প্রথা বা নিয়ম অনুযায়ী (সাঁওতালদের প্রথামতো বিয়ে হল)।

 

প্রথিত (p. 546) [ prathita ] বিণ. বিখ্যাত, প্রসিদ্ধ (প্রথিতযশা)। [সং. √ প্রথ্ + ত]। ̃ নামা (-মন্) বিণ. খ্যাতিমান, যার নাম প্রসিদ্ধ। ̃ যশা (-শস্) বিণ. বিপুল কীর্তিসম্পন্ন, খুব বিখ্যাত।

 

-প্রদ (p. 546) [ -prada ] বিণ. দানকারী, দেয় এমন (সুখপ্রদ)। [সং. প্র + √ দা + অ]। স্ত্রী. প্রদা।

 

প্রদক্ষিণ (p. 546) [ pradakṣiṇa ] বি. 1 হিন্দু আচার অনুযায়ী দেবমূর্তি বা পূজ্য ব্যক্তিকে দক্ষিণে রেখে পরিভ্রমণ; 2 (বাং.) পরিবেষ্টন; 3 (বাং.) আবর্তন, চতুর্দিকে পরিভ্রমণ (সূর্যকে প্রদক্ষিণ করে); 4 উপাসনা, বন্দনা। ☐ বিণ. অতিশয় অনুকূল। [সং. প্র + দক্ষিণ]।

 

প্রদত্ত (p. 546) [ pradatta ] বিণ. প্রদান করা হয়েছে এমন, অর্পিত। [সং. প্র + √ দা + ত]।

 

প্রদমিত (p. 546) [ pradamita ] বিণ. দমন শাসন নিবারণ বা সংযত করা হয়েছে এমন। [সং. প্র + দমিত]।

 

প্রদর (p. 546) [ pradara ] বি. স্ত্রীরোগবিশেষ, স্ত্রীজননেন্দ্রিয় থেকে শ্বেত স্রাব রোগ। [সং. প্র + √ দৃ + অ]।

 

প্রদর্শক (p. 546) [ pradarśaka ] বিণ. প্রদর্শনকারী, যে দেখায়। [সং. প্র + √ দৃশ্ + অক]। স্ত্রী. প্রদর্শিকা।

 

প্রদর্শন (p. 546) [ pradarśana ] বি. 1 সম্যক দর্শন, ভালোভাবে দেখা, পর্যবেক্ষণ। [সং. প্র + √ দৃশ্ + অন]; 2 দর্শন করানো, দেখানো; 3 উল্লেখ করা। [সং. প্র + √ দৃশ্ + ণিচ্ + অন]। প্রদর্শনী বি. যেখানে বিভিন্ন বস্তু বা প্রাণী বা ক্রী়ড়া-কৌতুকাদি দেখানো হয়, exhibition. প্রদর্শিত বিণ. দেখানো হয়েছে এমন।

 

প্রদর্শ-শালা (p. 546) [ pradarśa-śālā ] বি. জাদুঘর, museum. [সং. প্র + √ দৃশ্ + অ + শালা]।

 

প্রদর্শিত (p. 546) [ pradarśita ] দ্র প্রদর্শন।

 

প্রদাতা (p. 546) [ pradātā ] দ্র প্রদান।

 

প্রদান (p. 546) [ pradāna ] বি. 1 সম্যক দান; 2 সমর্পণ; 3 বিতরণ। [সং. প্র + √ দা + অন]। প্রদাতা (-তৃ), প্রদায়ক, প্রদায়ী (-য়িন্) বিণ. প্রদানকারী। স্ত্রী. প্রদাত্রী, প্রদায়িকা, প্রদায়িনী।
