নিষ্ঠা (p. 475) [ niṣṭhā ] বি. 1 দৃঢ় আস্হা, ভক্তি বা মনোযোগ (কর্মে নিষ্ঠা); 2 ধর্মানুষ্ঠানে শ্রদ্ধা বা অনুরাগ (নিষ্ঠাবান ব্রাহ্মণ)। [সং. নি + √ স্হা + অ + আ]। ̃ বান, (বর্জি.) ̃ বান্ (-বত্) বিণ. নিষ্ঠা আছে এমন। নিষ্ঠিত বিণ. নিষ্ঠা আছে এমন, নিষ্ঠাবান।

 

নিষ্ঠীবন, নিষ্ঠীব (p. 475) [ niṣṭhībana, niṣṭhība ] বি. থুতু। [সং. নি + √ ষ্টীব্ + অন, অ]।

 

নিষ্ঠুর (p. 475) [ niṣṭhura ] বিণ. 1 নির্দয়, নির্মম; 2 কঠোর (নিষ্ঠুর বাস্তব)। [সং. নি + √ স্হা + উর]। বি. ̃ তা।

 

নিষ্ঠেব, নিষ্ঠেবন (p. 475) [ niṣṭhēba, niṣṭhēbana ] যথাক্রমে নিষ্ঠীব ও নিষ্ঠীবন -এর বিরল রূপ।

 

নিষ্ঠ্যূত (p. 475) [ niṣṭhyūta ] বিণ. 1 উদ্গীর্ণ; 2 মুখ থেকে নিঃসারিত; 3 থু থু করে ফেলা হয়েছে এমন। [সং. নি + √ ষ্ঠীব্ + ত]।

 

নিষ্ণাত (p. 475) [ niṣṇāta ] বিণ. কুশল, নিপুণ, পটু; পারদর্শী (ব্যাকরণে নিষ্ণাত)। [সং. নি + √ স্না + ত]।

 

নিষ্পত্তি (p. 475) [ niṣpatti ] বি. 1 মীমাংসা (সমস্যার নিষ্পত্তি); 2 সিদ্ধি, সমাপ্তি (কার্যনিষ্পত্তি); 3 প্রয়োগ (বাঙ্নিষ্পত্তি); 4 (বাং.) মিটমাট, সমাধান (মোকদ্দমার নিষ্পত্তি)। [সং. নির্ + √ পদ্ + তি]।

 

নিষ্পত্র (p. 475) [ niṣpatra ] বিণ. (বৃক্ষ সম্বন্ধে) পত্রহীন (নিষ্পত্র বৃক্ষ)। [সং. নির্ + পত্র]।

 

নিষ্পন্ন (p. 475) [ niṣpanna ] বিণ. 1 মীমাংসিত; 2 সিদ্ধ (সংস্কৃত নিয়মে নিষ্পন্ন); 3 সম্পাদিত, সমাপ্ত; 4 উত্পন্ন, জাত। [সং. নির্ + √ পদ্ + ত]।

 

নিষ্পাদক (p. 475) [ niṣpādaka ] বিণ. নিষ্পত্তিকারক; নির্বাহ বা সম্পাদন করে এমন (কার্যনিষ্পাদক)। [সং. নির্ + √ পদ্ + ণিচ্ + অক]।

 

নিষ্পাদন (p. 475) [ niṣpādana ] বি. সম্পাদন; 2 নিষ্পত্তি, নির্বাহ (কার্যনিষ্পাদনের জন্য)। [সং. নির্ + √ পদ্ + ণিচ্ + অন]। নিষ্পাদনীয়, নিষ্পাদ্য বিণ. নিষ্পাদনের বা সম্পাদনের যোগ্য। নিষ্পাদিত বিণ. নিষ্পাদন করা হয়েছে এমন।

 

নিষ্পাপ (p. 475) [ niṣpāpa ] বিণ. পাপশূন্য, পাপ যাকে স্পর্শ করেনি (নিষ্পাপ শিশু); 2 পবিত্র। [সং. নির্ + পাপ]। নিষ্পাপী (বাংলায় প্রচলিত) বিণ. নিষ্পাপ।

 

নিষ্পিষ্ট (p. 475) [ niṣpiṣṭa ] বিণ. 1 অতিশয় পিষ্ট, চূর্ণিত ('হাতুড়ি-নিষ্পিষ্ট ট্রট্স্কি': সু.দ.); 2 দলিত, মর্দিত (অত্যাচারে নিষ্পিষ্ট মানুষ)। [সং. নির্ + √ পিষ্ + ত]।

 

নিষ্পুণ্য (p. 475) [ niṣpuṇya ] বিণ. পুণ্যহীন; 2 অন্যায়, অনুচিত; 3 অসুন্দর ('ক্লীবের নিষ্পুণ্য প্রত্যাখ্যান': সু. দ.)। [সং. নির্ + পুণ্য]।

 

নিষ্পেষ, নিষ্পেষণ (p. 475) [ niṣpēṣa, niṣpēṣaṇa ] বি. সম্পূর্ণরূপে চূর্ণন, পেষণ বা মর্দন; নিপীড়ন। [সং. নির্ + √ পিষ্ + অ, অন]। নিষ্পেষক বিণ. নিষ্পেষণকারী। নিষ্পেষিত বিণ. সম্পূর্ণ চূর্ণিত, পিষ্ট, মর্দিত (শত্রুকে নিষ্পেষিত করা)।

 

নিষ্প্রতিভ (p. 475) [ niṣpratibha ] বিণ. 1 প্রতিভাহীন, উজ্জ্বলতাহীন; ম্লান; 2 জড়বত্ (তু. অপ্রতিভ। তু. বিপ. সপ্রতিভ)। [সং. নির্ + প্রতিভা]।

 

নিষ্প্রদীপ (p. 475) [ niṣpradīpa ] বিণ. 1 প্রদীপহীন, দীপালোক নেই এমন; 2 অন্ধকার। ☐ বি. আলোকহীন রাত্রি, blackout. [সং. নির্ + প্রদীপ]।

 

নিষ্প্রবাহ (p. 475) [ niṣprabāha ] বিণ. প্রবাহ বা স্রোত নেই এমন (নিষ্প্রবাহ নদী)। [সং. নির্ + প্রবাহ]।

 

নিষ্প্রভ (p. 475) [ niṣprabha ] বিণ. 1 প্রভা নেই যার, দীপ্তিশূন্য, অনুজ্জ্বল; 2 নিরুত্তেজ, নিস্তেজ। [সং. নির্ + প্রভা]। বি. ̃ তা।

 

নিষ্প্রয়োজন (p. 475) [ niṣpraẏōjana ] বিণ. অনাবশ্যক, অদরকারি, নিরর্থক। ☐ বি. (বাং.) অদরকার, অপ্রয়োজন। [সং. নির্ + প্রয়োজন]।

 

নিষ্প্রাণ (p. 475) [ niṣprāṇa ] বিণ. 1 প্রাণহীন, মৃত (নিষ্প্রাণ দেহ); 2 নির্জীব, সজীবতা নেই এমন, ম্রিয়মাণ; 3 উদ্দীপক নয় এমন, আবেগহীন বা উদ্যমহীন (নিষ্প্রাণ বক্তৃতা)। [সং. নির্ + প্রাণ]। বি. ̃ তা।

 

নিষ্ফল (p. 475) [ niṣphala ] বিণ. 1 ফলহীন, ফল ধরে না এমন (নিষ্ফল গাছ); 2 বিফল, ব্যর্থ, পণ্ড (নিষ্ফল তর্ক, নিষ্ফল প্রয়াস); 3 অনর্থক, অকারণ (নিষ্ফল পূলক, নিষ্ফল আক্রোশ)। [সং. নির্ + ফল]। বি. ̃ তা। নিষ্ফলা বিণ. (স্ত্রী.) ফলহীনা; বন্ধ্যা।

 

নিষ্ফলা1 (p. 475) [ niṣphalā1 ] দ্র নিষ্ফল।

 

নিষ্ফলা2 (p. 475) [ niṣphalā2 ] বিণ. ফলহীন, ফল ধরে না এমন (নিষ্ফলা গাছ)। [সং. নির্ + ফল + বাং. আ (স্বার্থে)]। নিষ্ফলা বার যে দিনে কোনো ক্রিয়াকর্ম করলে ফলের সম্ভাবনা নেই।

 

নিসর্গ (p. 475) [ nisarga ] বি. 1 প্রকৃতি, প্রাকৃতিক পরিবেশ (নিসর্গ শোভা); 2 স্বভাব; 3 সৃষ্টি। [সং নি + √ সৃজ্ + অ]। ̃ চিত্র বি. প্রকৃতির বর্ণনাসংবলিত চিত্র। ̃ জ, নৈসর্গিক বিণ. 1 প্রাকৃতিক (নৈসর্গিক রূপ); 2 স্বভাবজাত, জন্মগত (নৈসর্গিত প্রতিভা)। ̃ বেদী (-দিন্), নিসর্গী (-র্গিন্) বি. প্রকৃতিবিজ্ঞানী, naturalist (বি. প.)।

 

নিসাড় (p. 475) [ nisāḍ় ] বিণ. 1 অসাড়; 2 সাড়াশব্দহীন; 3 নিস্পন্দ। [বাং. নি + সাড়া]।

 

নিসাড়া (p. 475) [ nisāḍ়ā ] বিণ. 1 অসাড়; 2 সাড়াশব্দহীন, নিঃশব্দ ('নিসাড়া হইয়া আয় লো সজনী': চণ্ডী.)। [বাং. নি +সাড়া]। নিসাড়ায় ক্রি-বিণ. নিঃশব্দে; চুপিচুপি। তু. নিঃসাড়।

 

নিসিন্দা (p. 475) [ nisindā ] বি. অত্যন্ত তেতো ভেষজ গাছবিশেষ। [দেশি]।

 

নিসূদক (p. 475) [ nisūdaka ] বিণ. বিনাশকারী, হন্তা, সূদন বা হনন করে এমন। [সং. নি + √ সূদ্ + অক]।

 

নিসূদন (p. 475) [ nisūdana ] বি. বিনাশকরণ, হনন। ☐ বিণ. বিনাশকারী (দৈত্যনিসূদন শ্রীহরি)। [সং. নি + √ সূদ্ + অন]।

 

নিসৃষ্ট (p. 475) [ nisṛṣṭa ] বিণ. 1 অর্পিত, ন্যস্ত; 2 নিক্ষিপ্ত (নিসৃষ্ট শর প্রত্যাহার করা অসম্ভব); 3 (বিশেষ কোনো অধিকার বা কার্যভারসহ) প্রেরিত, accredited (স. প.)। [সং. নি + √ সৃজ্ + ত]।

 

নিস্তনী (p. 475) [ nistanī ] বিণ. স্তনহীনা; অপুষ্ট স্তনযুক্তা। [সং. নি + স্তন + ঈ]।

 

নিস্তন্দ্র (p. 475) [ nistandra ] বিণ. তন্দ্রাহীন, নিদ্রাহীন, বিনিদ্র (নিস্তন্দ্র রাত্রি)। [সং. নির্ + তন্দ্রা]।

 

নিস্তব্ধ (p. 475) [ nistabdha ] বিণ. 1 সম্পূর্ণ নীরব, নিঃশব্দ; 2 সম্পূর্ণ নিস্পন্দ, সামান্য স্পন্দন বা নড়াচড়াও নেই এমন। [সং. নি + √ স্তন্ভ্ + ত]। বি. ̃ তা।

 

নিস্তরঙ্গ (p. 475) [ nistaraṅga ] বিণ. 1 তরঙ্গহীন, ঢেউ নেই এমন (নিস্তরঙ্গ নদী); 2 স্হির, অচঞ্চল; 3 (আল.) বৈচিত্র্যহীন (নিস্তরঙ্গ জীবন)। [সং. নির্ + তরঙ্গ]।

 

নিস্তরণ (p. 475) [ nistaraṇa ] বি. 1 পার হওয়া, উত্তরণ; 2 নিস্তার, নিষ্কৃতি, মুক্তি, উদ্ধার (এ ঘোর বিপদে নিস্তরণের আশা নেই); 3 নির্গমন, বহির্গমন। [সং. নির্ + √ তৃ + অন]।

 

নিস্তল (p. 475) [ nistala ] বিণ. 1 তলহীন, তলা নেই অর্থাত্ কোনো অংশ সমতল নয় এমন; 2 বর্তুলাকার, নিটোল। [সং. নির্ + তল]। বি. ̃ তা।

 

নিস্তার (p. 475) [ nistāra ] বি. উদ্ধার, অব্যাহতি, নিষ্কৃতি (তার হাত থেকে তোমার নিস্তার নেই); 2 পরিত্রাণ, ত্রাণ, মুক্তি (ঈশ্বরই নিস্তার করবেন)। [সং. নির্ + √ তৃ + অ]। ̃ ক বিণ. নিস্তারকারী।

 

নিস্তারিণী (p. 475) [ nistāriṇī ] বিণ. তারিণী, নিস্তারকারিণী, মুক্তিদায়িনী। ☐ বি. দুর্গাদেবী। [সং. নির্ + √ তৃ + ণিচ্ + ইন্ + ঈ]।

 

নিস্তুষ (p. 475) [ nistuṣa ] বিণ. তুষহীন, যাতে তুষ নেই এমন; খোসা ছাড়ানো হয়েছে এমন। [সং. নির্ + √ তুষ্ + অ]।

 

নিস্তেজ (p. 475) [ nistēja ] বিণ. 1 তেজ নেই এমন, দুর্বল (নিস্তেজ পশু); 2 দীপ্তিহীন, অনুজ্জ্বল, ক্ষীণ (নিস্তেজ আলোক); 3 শক্তি বা প্রভা হ্রাস পেয়েছে এমন। [সং নির্ + তেজস্]।

 

নিস্তেজা (p. 475) [ nistējā ] (-জস্) বিণ. নিস্তেজ। [সং. নির্ + তেজস্ = নিস্তেজাঃ]।

 

নিস্ত্রিংশ (p. 475) [ nistriṃśa ] বি. খ়ড়্গবিশেষ (ত্রিশ আঙুলের চেয়ে বেশি দীর্ঘ বলে)। ☐ বিণ. 1 নির্দয়, নিষ্ঠুর; 2 হিংসাপরায়ণ। [সং. নির্ (=নির্গত অর্থাত্ অধিক) + ত্রিংশ]।

 

নিস্ত্রৈগুণ্য (p. 475) [ nistraiguṇya ] বিণ. সত্ত্ব রজঃ ও তমঃ এই ত্রিগুণের অধীনতা থেকে মুক্ত। [সং. নির্ + ত্রিগুণ + য]।

 

নিস্পন্দ (p. 475) [ nispanda ] বিণ. 1 স্পন্দনহীন, অকম্পিত (নিস্পন্দ বৃক্ষপত্র); 2 অসাড়, স্হির (নিস্পন্দ দেহ)। [সং. নি + √ স্পন্দ্ + অ]। বি. ̃ তা।
